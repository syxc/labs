# Aside Guide Pack

这是一套整理好的 Aside 浏览器中文实用文档，重点围绕 AI 使用方式、提示词模板、避坑经验和设置建议。

当前目录已经按知识库结构整理，适合作为一个可长期维护的 Aside 文档包来使用。
