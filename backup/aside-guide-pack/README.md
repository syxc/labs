# Aside AI 中文指南包

> 一个面向 GitHub 阅读、长期维护和日常复用的 Aside AI 中文知识库。

这套文档包主要围绕：

- Aside AI 的核心工作方式
- 高质量提示词模板
- 常见误区与避坑方法
- 快捷键、权限和工作流建议

如果你只是第一次打开这个仓库，建议先从下面 3 个入口开始：

- [个人常用提示词收藏](./templates/07-aside-ai-personal-prompts.md)
