# Aside Guide Pack

一套面向 GitHub 阅读和长期维护的 Aside 浏览器中文文档包，重点围绕：

- Aside AI 的核心工作方式
- 高质量提示词模板
- 常见误区与避坑方法
- 快捷键、权限和工作流建议

如果你只是第一次打开这个仓库，建议先从下面 3 个入口开始：

- [完整指南](./guides/01-Aside浏览器AI完整指南.md)
