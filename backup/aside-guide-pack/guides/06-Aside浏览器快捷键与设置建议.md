# Aside 浏览器快捷键与设置建议

这份文档专门整理 Aside 在日常使用中最值得知道的快捷键、常用设置和推荐搭配方式，重点仍然围绕 AI 使用体验。

---

# 第一部分：最常用快捷键速查

## 核心快捷键

### 打开或关闭侧边栏
- `Cmd/Ctrl + S`

适合场景：
- 当前页很重要，想直接从 side panel 发任务
- 一边看页面一边和 AI 交互

### 打开 Ask Aside
- `Cmd/Ctrl + E`

适合场景：
- 快速发起 AI 任务
- 从浏览器任意位置直接开始

### 新建任务
- `Cmd/Ctrl + Shift + E`

适合场景：
- 明确知道要新开一个任务
- 不想把问题混在当前上下文里

### 复制当前 URL
- `Cmd/Ctrl + Shift + C`

适合场景：
- 快速把页面链接发给别人
- 把当前页作为参考信息粘贴进任务里

### 分屏标签页
- `Cmd/Ctrl + Shift + \\`
- `Cmd/Ctrl + Shift + -`

适合场景：
- 一边看源页面，一边让 Aside 操作目标页面
- 对比两个页面
- 左边看 dashboard，右边写总结
- 左边看合同，右边整理表格

# 第二部分：最值得优先掌握的 3 个操作

## 1. Ask AI
最适合：
- 直接发任务
- 跨页面操作
- 搜索、下载、整理、草拟

推荐习惯：
每次都写清楚：
- 用哪个页面/网站
- 要什么结果
- 输出到哪里
- 停在哪里

## 2. Side Panel
最适合：
- 当前页本身很关键
- 想让 Aside 基于眼前页面做事
- 不想让 AI 自己重新找入口

推荐习惯：
从关键页面打开 side panel，并明确写“使用当前页面”。

## 3. Split Tab
最适合：
- 对照页面做事
- 一边观察任务，一边看目标网站
- 人工核对 AI 输出

推荐习惯：
复杂任务时尽量分屏，减少来回切换标签。

# 第三部分：AI 设置建议

## 1. AI Provider 怎么选

Aside 的模型来源大体可以理解为三类：
- Aside 自带
- 复用现有订阅
- 自带 API key

## 推荐选择思路

### 日常轻量任务
优先默认 provider。

适合：
- 网页总结
- 草稿生成
- 下载整理
- 常规信息提取

### 复杂推理任务
适合切更强模型。

例如：
- 合同分析
- 多条件对比
- 大量文本归纳
- 复杂文件处理

### 你已经有 ChatGPT/Claude 订阅
可以优先接入已有订阅，减少重复付费。

# 第四部分：权限设置建议

## 1. Read only
适合：
- 第一次试跑任务
- 只想先让 AI 看网页或文件
- 总结和提取类任务

## 2. Guard
这是最推荐的日常模式。

适合：
- 下载文件
- 生成文档
- 处理指定文件夹里的内容
- 风险相对可控的常规工作

### 推荐搭配
- Guard
- 指定 working folder
- 明确写保存位置

## 3. Full access
适合：
- 确实需要跨很多目录找文件
- 复杂本地整理任务

但不建议默认使用。

# 第五部分：Password Manager 设置建议

## 推荐做法
如果你经常让 Aside 处理真实网站任务，建议提前把常用网站凭据保存好。

例如：
- Gmail
- Slack
- Notion
- Rippling
- Stripe
- CRM
- 各类 vendor portal

## 推荐访问策略
如果你追求实用和稳妥的平衡，优先考虑：
- `While unlocked`

这样日常使用比较顺手，也比完全放开更稳。

## 要有心理预期
即使密码能自动填，遇到这些仍然可能需要你补一步：
- MFA
- 验证码
- passkey 批准
- CAPTCHA
- 身份验证

# 第六部分：Chat Settings 建议

## Follow-up 行为

### Queue
适合：
- 当前任务大方向没问题
- 你的补充可以稍后再处理

### Steer
适合：
- AI 正在走错路
- 你要立刻纠正方向
- 你要阻止它执行某个动作

## 推荐习惯
平时默认理解为：
- 补充说明，用 Queue 思路
- 立即纠偏，用 Steer 思路

如果任务涉及真实操作，学会及时 Steer 很重要。

# 第七部分：最值得调整的使用习惯

## 习惯 1：当前页关键时，用 side panel
例如：
- 当前工单
- 当前邮件线程
- 当前合同页
- 当前 dashboard
- 当前后台详情页

## 习惯 2：大任务先写边界
固定加：
- 不要发送
- 提交前停下
- 不要修改设置
- 遇到验证码先问我

## 习惯 3：第一次先小权限试跑
流程跑顺之后，再慢慢放大权限。

## 习惯 4：重复任务尽早做成 routine
如果一件事你已经做过 2 到 3 次，就值得自动化。

## 习惯 5：复杂任务尽量分步
不要把下载、汇总、写邮件、发消息全塞在一条提示词里。

# 第八部分：Selection 和 Lasso 的建议用法

## 文字选择
适合：
- 总结段落
- 翻译内容
- 解释合同条款
- 提炼重点

## Lasso 选择
适合：
- 截一块区域给 AI 理解
- 识别局部代码
- 搜图
- 读图片中的局部信息

## 推荐区分法
### 小问题
直接选择网页局部内容。

### 大任务
用 Ask AI 或 side panel。

# 第九部分：最推荐的组合用法

## 组合 1：当前页 + Side Panel
适合：
- 合同提取
- 邮件草稿
- support thread 回复
- 当前后台信息整理

模板：
“使用当前页面，提取重点并整理成表格。不要离开当前页面上下文。”

## 组合 2：Ask AI + Guard + 指定目录
适合：
- 下载和整理文件
- 处理 Downloads 里的 PDF
- 生成 markdown 或 spreadsheet

模板：
“使用 Downloads 里的文件生成汇总表，保存到 Downloads/reports。不要删除原文件。”

## 组合 3：Split Tab + Ask AI
适合：
- 页面对比
- 一边核对，一边整理
- 一边看 dashboard，一边写 summary

## 组合 4：Routine + 明确输出模板
适合：
- 周报
- 每日检查
- 周期发票下载
- 周期 dashboard 检查

# 第十部分：新手建议的默认配置

如果你刚开始用 Aside，我建议你先形成这套默认配置：

## 默认权限
- 先用 Guard

## 默认文件位置
- 尽量写清保存到 Downloads 或指定文件夹

## 默认边界句
- “不要发送”
- “提交前停下”
- “不要修改设置”
- “遇到验证码先问我”

## 默认任务风格
- 一次只解决一个明确目标
- 能拆成两步就尽量拆
- 当前页面重要时一定写“使用当前页面”

---

# 第十一部分：最适合长期保留的个人工作流

## 工作流 1：先读后做
1. Read only 看一遍
2. 确认路径对
3. 再切 Guard 执行

## 工作流 2：先草拟再确认
1. 让 AI 先找资料
2. 让 AI 起草
3. 你最后确认发送/提交

## 工作流 3：先手动跑通，再做 routine
1. 手动成功做 2 到 3 次
2. 固化提示词模板
3. 再自动化

---

# 第十二部分：一页版结论

如果只记住最重要的建议：

1. 当前页重要时，用 side panel
2. 跨步骤任务，用 Ask AI
3. 默认先用 Guard，不要一上来 Full access
4. 所有高风险动作都写“先停下”
5. 跑偏立刻纠正
6. 重复任务改成 routine
7. 多用 split tab 做人工核对
8. 复杂任务尽量分两步

---

# 第十三部分：我最推荐你固定复制的 3 句

## 句子 1
“使用当前页面，完成[目标]，不要离开当前页面上下文。”

## 句子 2
“把结果保存到 Downloads/[文件夹名]，不要删除原文件。”

## 句子 3
“如果遇到验证码、MFA、发送、付款或提交，先停下来问我。”
